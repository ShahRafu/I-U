(100 / (1 + RS))\nWhere RS = Average Gains / Average Losses (14-period)\n\n📈 Interpretation:\nRSI < 30 → Oversold (ক্রয়ের সুযোগ)\nRSI > 70 → Overbought (বিক্রয়ের সুযোগ)\nRSI 40-60 → Neutral (অপেক্ষা করুন)\n```\n\n### MACD (Moving Average Convergence Divergence)\n```\nMACD Line = 12-period EMA - 26-period EMA\n\n📈 Interpretation:\nMACD > 0 → Bullish (ঊর্ধ্বমুখী)\nMACD < 0 → Bearish (নিম্নমুখী)\nMACD Crossover → Trend Change (ট্রেন্ড পরিবর্তন)\n```\n\n### EMA (Exponential Moving Average)\n```\nEMA = Price × K + EMA(previous) × (1 - K)\nWhere K = 2 / (Period + 1)\n\n📈 Trend Detection:\nPrice > EMA20 > EMA50 → Strong Uptrend\nPrice < EMA20 < EMA50 → Strong Downtrend\n```\n\n### Confidence Calculation\n```\nFinal Confidence = \n  (Direction Confidence × 40%) +\n  (RSI Signal × 35%) +\n  (MACD Signal × 25%)\n\n✅ Trade Execute IF: Confidence ≥ 80%\n```\n\n---\n\n## 📈 পারফরম্যান্স মেট্রিক্স\n\n### প্রক্রিয়াকরণ গতি\n\n```\n⚡ Market Analysis Loop: 2 seconds\n⚡ Trade Decision: < 100ms\n⚡ Auto-Execution: < 200ms\n⚡ Database Write: Async (non-blocking)\n```\n\n### মেমরি দক্ষতা\n\n```\n💾 Price Buffer: Max 100 prices (~5KB)\n💾 Trade History: SQLite (Optimized)\n💾 Average RAM Usage: ~80-120 MB\n```\n\n### ব্যাটারি প্রভাব\n\n```\n🔋 Standby: ~3-5% per hour\n🔋 Active Trading: ~8-12% per hour\n🔋 Recommendation: Plug-in during trading hours\n```\n\n---\n\n## 🚀 APK ডাউনলোড সেটআপ\n\n### স্বয়ংক্রিয় বিল্ড সিস্টেম\n\nএটি GitHub Actions ব্যবহার করে, তবে প্রথমে:\n\n```\n1.
